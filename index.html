Recon Helper

Browser extension for reconnaissance
April 2026

A Chrome and Brave extension that gathers recon data from the page you are on. I set it up and tested it against its core features.

  • Validated URL, domain and IP extraction.
  • Checked external JavaScript file discovery.
  • Tested DNS-over-HTTPS IP resolution.
  • Tried the shortcuts to Shodan, Wayback Machine, WHOIS, crt.sh, SecurityTrails and URLScan, using AI assistance to troubleshoot problems.
